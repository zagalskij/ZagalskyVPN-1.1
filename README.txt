Закальский VPN — Signature Edition (iPhone, iOS 16+)

ПЕРСОНАЛИЗАЦИЯ
При первом запуске введите имя и дату рождения. После сохранения на главном
экране появится комплимент с вашим именем. При новом запуске меняется текст,
а в день рождения приложение выводит поздравление. Имя и дату можно изменить
через значок профиля в правом верхнем углу. Эти данные хранятся на iPhone.

AMNEZIAWG
Нажмите «Добавить конфигурацию» и вставьте текст с разделами [Interface]
и [Peer] или откройте файл .conf. Если у вас ссылка vpn://, экспортируйте
профиль через «Оригинальный формат AmneziaWG» в AmneziaVPN.
https://docs.amnezia.org/ru/documentation/instructions/use-amneziawg-app/

Сохраните конфигурацию, разрешите iOS добавить VPN и нажмите «Подключить».
Конфигурация хранится в Связке ключей iOS. Проверьте подключение, открыв на
iPhone ресурс, который должен быть доступен через ваш сервер.

СБОРКА НА MAC
1. Установите Xcode 16 или новее и Go 1.26.x.
2. Откройте ZagVPN.xcodeproj и выберите схему ZagVPN.
3. В Signing & Capabilities укажите одну и ту же команду Apple Developer
   для ZagVPN и PacketTunnel. Обе цели используют Network Extensions
   (Packet Tunnel) и общую группу Keychain Sharing.
4. Если требуется уникальный Bundle ID, задайте ZAKALSKY_BUNDLE_ID в
   настройках проекта для Debug и Release. Идентификатор расширения
   и группа Связки ключей будут сформированы автоматически.
5. Выберите подключённый iPhone и нажмите Run.

СБОРКА ЧЕРЕЗ GITHUB ACTIONS
1. Загрузите распакованные файлы проекта в ветку main своего репозитория,
   включая скрытую папку .github.
2. Во вкладке Actions откройте Build Zagalsky VPN IPA. Workflow запускается
   при push в main и вручную через Run workflow.
3. Скачайте артефакт ZagalskyVPN-unsigned и извлеките ZagalskyVPN.ipa.
4. Для установки подпишите приложение и PacketTunnel сертификатом и
   профилями одной команды Apple Developer. Подпись должна включать
   Network Extensions (Packet Tunnel) и общую группу Keychain Sharing.
   Можно также подписать и установить проект через Xcode.

Используется движок AmneziaWG Apple v3.1.5. Информация об исходном коде и
лицензиях находится в Vendor/AmneziaWG. Автосборка в текущей среде
не запускалась. В архиве содержится исходный проект.
